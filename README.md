# senior_project
檔案用途說明

**app.py**
這是一個簡單的即時姿態辨識演示程式（Proof of Concept）。它使用 MediaPipe 的 Pose 模型從電腦攝影機（WebCam）讀取即時影像，偵測人體骨架，並在視窗中繪製骨架線條和關節點。程式會持續顯示攝影機畫面，並即時更新骨架追蹤。用途是測試基本的姿態辨識功能，驗證 MediaPipe 的安裝和運作，顯示即時的骨架視覺化。沒有評分邏輯或複雜的互動，只是純粹的視覺化演示。使用者可以按 'q' 鍵或點擊視窗關閉按鈕退出程式。

**config.py**
設定檔案，集中管理系統的所有常數和參數。它定義了 MediaPipe 模型的路徑、偵測信心度閾值（min_detection_confidence）、追蹤信心度閾值（min_tracking_confidence）、骨架繪圖的顏色設定（關節點和連線的顏色、粗細）、以及骨架連線的定義。用途是將所有可調整的參數集中管理，便於開發者和使用者調整系統行為，例如提高信心度以減少誤偵測，或改變視覺樣式以適應不同需求。修改此檔案可以影響整個系統的準確性和外觀。

**dance_standard.json**
JSON 格式的資料檔案，儲存從老師舞蹈影片（teacher_dance.mp4）中預先提取的標準骨架資料。每個幀（frame）包含時間戳記（timestamp_ms）和 33 個 MediaPipe 關鍵點的座標資訊（x, y, z, visibility）。用途是作為舞蹈評分的基準資料庫，讓系統能夠比較學生的即時姿態與標準動作的差異。這個檔案是預處理階段的產物，由 extract_standard.py 生成，並在評分過程中被動態載入使用。

**dtw_scoring.py**
動態時間規整（Dynamic Time Warping, DTW）評分模組，實現了舞蹈動作的序列比對演算法。它包含學生骨架緩衝區的管理（create_student_buffer, update_student_buffer）和 DTW 距離計算（compute_dtw_score）。用途是處理學生動作的時間序列與標準動作的比對，即使動作速度不同也能準確評分。模組會維護一個滑動視窗的學生骨架資料，並使用 DTW 演算法計算相似度分數，支援即時舞蹈教學的評分邏輯。

**extract_standard.py**
預處理工具腳本，專門用於從老師的舞蹈影片（teacher_dance.mp4）中提取標準骨架資料。它使用 MediaPipe 的 Pose 模型處理影片的每一幀，擷取骨架座標，並將結果儲存到 dance_standard.json。程式會檢查影片是否存在，並自動生成或更新標準資料。用途是建立評分基準，在專案初始化或更換舞蹈影片時運行此腳本，確保標準資料與影片同步。

**extractor.py**
姿態提取器的類別模組，封裝了 MediaPipe 的 PoseLandmarker 模型，提供統一的介面用於從影像中提取骨架資料。類別支援不同的模式（如 VIDEO），並允許設定偵測和追蹤的信心度閾值。用途是模組化地處理姿態提取任務，供其他檔案（如 main.py 或 extract_standard.py）調用，避免重複程式碼。類別會處理影像的 RGB 轉換和 MediaPipe 的處理流程，返回標準化的骨架資料結構。

**ghost_visualizer.py**
鬼影視覺化模組，負責生成舞蹈教學系統中的老師面板和學生鬼影效果。它包含 create_teacher_panel 和 create_ghost_panel 函數，分別處理老師影片的顯示和學生的鬼影疊加。用途是在學生畫面上疊加半透明的標準骨架（鬼影），讓學生能夠即時比較自己的動作與標準動作的差異。模組會根據播放狀態和骨架資料動態生成視覺效果，增強教學互動性。

**main_test.py**
功能測試版本的主要應用程式，是 main.py 的增強版，整合了完整的舞蹈教學系統功能。它同時處理 WebCam（學生）和老師影片，實現即時評分、鬼影視覺化、速度控制和 DTW 評分。支援按 's' 開始播放、空白鍵暫停/繼續、'c' 顯示/隱藏速度控制器（滑鼠調整倍速）。用途是測試所有模組的整合運作，提供完整的互動體驗，包括分數顯示、時間追蹤和視窗管理。這個檔案是專案的核心測試版本。

**main.py**
主要應用程式，實現了舞蹈教學系統的基本邏輯。它同時處理 WebCam（學生）和老師影片，進行即時姿態比較和評分。按下 's' 開始播放影片並評分，按下 'q' 退出。畫面會拼接顯示老師和學生的影像，並在學生畫面上顯示分數和時間。用途是整合核心功能，提供基本的互動體驗，但功能相對簡化，適合快速測試。

**pose_utils.py**
姿態處理工具函數模組，包含骨架正規化（normalize_pose）和誤差計算（calculate_pose_error）等核心演算法。正規化函數會將骨架對齊到骨盆中心並進行縮放，使不同身材的人能夠公平比較；誤差計算函數比較學生骨架與標準骨架的歐幾里得距離。用途是處理骨架資料的數學運算，支援評分邏輯的準確性。這些函數是評分系統的數學基礎。

**py_video.py**
專門的視訊處理腳本，聚焦於膝蓋角度計算和蹲姿動作的評分。它從舞蹈影片和 WebCam 讀取影像，計算膝蓋彎曲角度，並根據角度範圍提供即時回饋（如 "Good! Keep going" 或 "Squat down!"）。用途是針對特定健身動作（蹲姿）的即時指導，類似於健身應用，提供語音或文字提示。程式會持續顯示兩個視窗，並根據角度變化給予動態回饋。

**speed_controller.py**
速度控制模組，提供舞蹈播放速度的調整功能。它包含 draw_speed_controller 和 get_speed_from_click 函數，分別負責繪製速度控制介面和處理滑鼠點擊事件。支援 0.5x、1.0x、1.5x、2.0x 等倍速選項。用途是讓使用者能夠調整老師影片的播放速度，適應不同學習節奏。模組會根據使用者輸入動態調整播放參數。

**standard_data.py**
標準資料管理模組，負責載入和更新標準骨架資料。它包含 check_and_update_standard 和 load_standard_pose_data 函數，前者檢查 dance_standard.json 是否與影片同步，後者載入資料到記憶體。用途是確保標準資料的完整性和時效性，在系統啟動時自動檢查並更新，避免因影片更換導致資料不匹配的問題。

**visualizer.py**
視覺化模組，定義了 draw_skeleton 函數，用於在 OpenCV 畫布上繪製人體骨架。函數會根據骨架資料繪製關節點和連線，使用指定的顏色和粗細。用途是將抽象的骨架座標轉換為視覺輸出，支援各種繪圖需求，如在影像上疊加骨架或生成預覽圖。模組提供靈活的繪圖介面。

**README.md**
專案說明檔案，包含專案概述、檔案用途說明、安裝步驟、使用說明和貢獻指南。用途是文檔化專案，讓開發者和使用者快速了解系統架構和操作方法。

**pycache/**
Python 的快取目錄，存放編譯後的 .pyc 檔案。用途是加速 Python 程式執行，無需手動管理。當 Python 檔案被執行時，會自動生成對應的快取檔案。

整體資料流向
這個系統的資料流向大致如下（以 main_test.py 為核心）：

輸入階段：
- WebCam（學生影像）和老師影片（teacher_dance.mp4）同時被讀取。
- 學生影像通過 MediaPipe 的 Pose 模型提取即時骨架資料（33 個關鍵點的 x, y, z, visibility）。
- 標準資料從 dance_standard.json 載入。

處理階段：
- 根據播放時間（elapsed_ms），從標準資料中找到對應的骨架幀。
- 使用 pose_utils.py 將學生和標準骨架正規化（對齊骨盆、縮放）。
- 使用 dtw_scoring.py 計算 DTW 相似度分數。
- 根據使用者輸入調整播放速度（speed_controller.py）。

輸出階段：
- 使用 ghost_visualizer.py 生成老師面板和學生鬼影效果。
- 在學生畫面上繪製骨架和鬼影（使用 visualizer.py 或 MediaPipe）。
- 顯示分數、時間、速度，並拼接老師和學生畫面。
- 如果是 py_video.py，額外計算膝蓋角度並給予文字回饋。

總體流程：資料從影像 → 骨架提取 → 正規化比較 → DTW 評分 → 視覺化輸出。標準資料（dance_standard.json）是預先從老師影片提取的基準，而即時資料來自 WebCam。系統支援即時評分、鬼影教學和速度調整。
